Try it in ten minutes — a Puck.js that measures what it was told to do

Home Assistant switches the LED; the Puck's own light sensor reports the result back as illuminance. The loop is closed by a measurement, not by an echo.

a — what you need

  • A Puck.js — from the Web IDE, or one command
  • Something opaque to cover it — a mug upside down will do
  • Home Assistant with Bluetooth — an adapter, or an ESPHome proxy
  • About ten minutes — docs/try-it.md walks both routes
